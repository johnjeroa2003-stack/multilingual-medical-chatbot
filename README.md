# 🩺 Multilingual Medical Support Chatbot

## 📌 Project Overview

The Multilingual Medical Support Chatbot is an AI-powered healthcare assistant developed using Streamlit and Hugging Face Transformers.

This chatbot can:
- Detect the user's language automatically
- Translate non-English queries into English
- Generate basic medical guidance using an AI language model
- Translate the response back to the user's original language

The system helps users receive simple medical guidance in multiple languages through an easy-to-use web application.

> ⚠️ Disclaimer:
> This chatbot is developed for educational purposes only and should not be considered a replacement for professional medical advice or diagnosis.
